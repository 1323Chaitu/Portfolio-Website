# Professional Portfolio (React + Vite)

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Customize
- Edit your name, introduction, social links, and email in `src/App.jsx`.
- Replace the sample projects and skills in the arrays at the top of `src/App.jsx`.
- Add your resume as `public/resume.pdf` (create the `public` folder if needed).
- The contact form is currently a front-end demo. Connect it to Formspree, EmailJS, or your own backend to receive submissions.

Built with React, HTML, CSS, and JavaScript.
